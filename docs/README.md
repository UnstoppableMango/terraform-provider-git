# docs/

This directory holds two distinct kinds of documentation.

## Design docs (hand-written)

- [DESIGN.md](DESIGN.md).
- [...FUTURE_CAPITALIZED_FILES.md]

## Registry docs (generated)

Produced by `tfplugindocs generate` (`make docs`) from each schema's `MarkdownDescription`

- `index.md`
- `resources/*.md`
- `data-sources/*.md`
- `guides/*.md`

Don't hand-edit the `<!-- schema generated by tfplugindocs -->` sections; edit the Go source and regenerate.
